Este repositorio explica como ejecutar y aplicar las políticas del CIS Ubuntu Linux 24.04 LTS Benchmark v1.0.0.

Hay 3 archivos adjuntos:
  1. CIS Wazuh Documentación.zip: PDFs con pasos e instrucciones.
  2. Tabla políticas CIS Ubuntu.xlsx: tabla visual de políticas a aplicar.
  3. CIS-Ubuntu.sh: script Bash que ejecuta las correcciones.
